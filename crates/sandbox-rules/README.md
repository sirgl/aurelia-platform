# sandbox-rules

A small reference rules module for the kernel (territory, units, cities, one income, simple combat). It shows how little a module needs and is used to test the platform without any real game.

Part of Aurelia (<https://github.com/sirgl/aurelia-platform>, placeholder): a turn-based strategy game
platform with deterministic rules modules. Licensed under either of MIT or Apache-2.0 at your option
(see `LICENSE-MIT` and `LICENSE-APACHE`).
