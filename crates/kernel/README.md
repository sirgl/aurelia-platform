# kernel

The deterministic 4X kernel: map, players, cities, units, knowledge, navigation, the effect engine, the rules compiler, saves and replay hashing. It is generic over a rules module (`RulesModule`); a game supplies the rules and the content.

Part of Aurelia (<https://github.com/sirgl/aurelia-platform>, placeholder): a turn-based strategy game
platform with deterministic rules modules. Licensed under either of MIT or Apache-2.0 at your option
(see `LICENSE-MIT` and `LICENSE-APACHE`).
